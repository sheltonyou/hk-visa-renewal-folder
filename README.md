# 香港续签准备文件夹模板

一份适用于香港**人才入境计划**（高才通 / 优才 / IANG / 专才 等）续签准备的文件夹结构模板。基于真实续签经验整理，公开给所有人 fork 走 DIY。

**本模板以高才通续签为示例，优才和 IANG 的材料结构大同小异，按你自己的签证类型微调即可。**

## 为什么用这个

香港入境处续签的上传位置就两个：

- **香港身份证**：1 个档案，≤ 5MB
- **其他文件**：最多 5 个档案，每个 ≤ 5MB

也就是说，你一两年攒下的几十张工资单、银行月结、合约、税单、强积金记录、学历认证，最终要压缩进 5 个 ≤5MB 的文件。这不是收材料，是一份**打包工作**。

这套结构把准备工作分两层：

- **第一层 · 素材库**（1-10 编号文件夹）：按材料类别堆原始 PDF，给自己看，可以复用（下次续签 / 永居 / 受养人单签都从这抽）。
- **第二层 · 递交版**（`0_上传用/`）：合并 + 压缩 + 命名后塞进入境处那 5 个槽。

## 文件夹结构

```
.
├── 0_上传用/                    # 最终递交版（合并+压缩后）
│   ├── 个人材料/
│   │   ├── 1_港澳通行证/
│   │   ├── 2_香港身份证/
│   │   └── 3_小白条/
│   ├── 公司部分/                # 自雇 / 经营公司路径才有
│   │   ├── 公司其他/
│   │   ├── 公司财报/
│   │   └── 商业登记证/
│   ├── 受养人材料/              # 全家陪签才有
│   └── 证明部分/                # 工作证明 5 个 PDF
├── 1_港澳通行证/                # 1-3：证件类
├── 2_香港身份证/
├── 3_小白条/
├── 4_收入流水/                  # 4-8：工作证明（滚动 12-24 个月）
│   ├── 公司的每月工资单/
│   └── 银行每月 statement/
├── 5_公司背书/
├── 6_纳税交金/
├── 7_生活证明/
├── 8_学信网认证/                # 早期批次专属，新批次不用
├── 9_受养人/                    # 配偶 / 未成年子女
└── 10_公司部分/                 # 自雇 / 经营自己公司才用
    ├── 公司财报/
    └── 商业登记证/
```

## 怎么用

1. **Fork 或 clone** 到本地。
2. **每月填充** — 工资单、银行 statement 这些每月一份的，发到邮箱就立刻丢进对应文件夹。**不要等续签前 3 个月才翻历史**。
3. **续签前** — 把 1-10 里的素材合并 + 压缩 + 改名，塞进 `0_上传用/证明部分/`。
4. **递交** — 上传到入境处的续签页面。
5. **续签结束** — `0_上传用/` 归档备份。**1-10 文件夹继续滚动留**，下次续签 / 永居 / 受养人单签直接抽。

## 每一类是什么

详细说明见配套文章：[续签准备 DIY 手册：开源一套好用的文件结构](#)（占位，公众号链接发布后补）

简要：

| 文件夹 | 内容 | 哪里拿 |
|---|---|---|
| 1 港澳通行证 | EEP 正反面扫描 | 内地公安出入境 |
| 2 香港身份证 | HKID 正反面扫描 | 入境处 |
| 3 小白条 | 首次签注入境时入境海关给的白色小纸条 | 入境时领取，丢失到入境处将军澳总部补办 |
| 4 收入流水 | 银行 statement + 公司每月工资单（滚动 12-24 月） | 银行 App / 雇主 HR |
| 5 公司背书 | 雇用合约 + 在职证明 | 入职签的合约 / HR 开新在职证明 |
| 6 纳税交金 | 强积金记录 + 个人报税表 | 积金易官网 / 税务局个人税务网站 |
| 7 生活证明 | 住香港：印花税厘印 + 租约 + 水电单；不住：解释信 | — |
| 8 学信网认证 | 中国高等教育学位在线验证报告 | 学信网 chsi.com.cn（仅早期批次需要补） |
| 9 受养人 | 配偶 / 子女 的 EEP + HKID + 小白条 | 同 1-3，按人备份 |
| 10 公司部分 | BR + CR + 公司财报 + NAR1 + MPF 缴纳 | 仅自雇 / 经营自己公司路径需要 |

## 打包 2 件事

1. **合并同类项** — 12-24 个月的银行 statement 合成 1 个 PDF，其他类同理。
2. **压缩 ≤5MB** — 合并完轻松超出 5MB，必须压缩。macOS 自带 Preview "导出 → 减小档案大小" 够用。
