# Examples — 演示用虚构文件夹

这个目录下的所有文件都是 **100% 虚构的演示样本**，跟任何真实客户无关。

## 命名约定 — "高才通" 既是签证类型也是 demo 客户名

虚构客户的名字是 `高才通` （拼音 `GAOCAITONG`），跟签证类型同名。这是个有意为之的双关：

- 看到 `EEP_GAOCAITONG_BACK.jpg` 这种文件名，**任何人一眼就知道是 demo，不可能是真人**
- 看到 `高才通在职证明.pdf` 这种文件名，自带"这是演示文件" 的元信号

## 用途

公众号文章 / 文档教程 / 截图分享时，**所有展示文件夹结构的截图必须从这里截**，不能用真实客户的文件夹（即使打码）。

教训来源：2026-06-05 公众号文章用真实客户文件夹打码后发布，被客户识别出投诉，文章删稿。打码可以防外人，防不了当事人自己。详见维护 issue 或 commit 历史。

## 结构

`examples/高才通_高才/` 下面是完整的两层结构（跟根目录 1-10 文件夹一致），里面填了占位文件名，文件本身是空的：

- `0_上传用/` — 递交版（按入境处视角合并后的 5 个 PDF + 个人/受养人/公司材料）
- `1-3 证件类` — 港澳通行证 / HKID / 小白条
- `4-8 工作证明` — 收入流水 / 公司背书 / 纳税交金 / 生活证明 / 学信网
- `9 受养人` — 配偶/子女材料
- `10 公司部分` — 自雇/经营路径

## 如何重拍截图

1. 在本地 `git clone` 这个仓库
2. 用 Finder 打开 `examples/高才通_高才/`，整理成你想展示的视图（展开/折叠/排序）
3. 截图
4. 发布到公众号 / 文档 / Slack 等

所有占位文件是 0 字节空文件，关键是文件名和文件夹结构呈现，不是文件内容本身。
